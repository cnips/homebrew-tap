# CNIPS Homebrew tap

Homebrew formulae for [CNIPS](https://cnips.io) tools.

```bash
brew tap cnips/tap
brew install cnips
```

Or in one step:

```bash
brew install cnips/tap/cnips
```

Upgrade with `brew upgrade cnips`.

## What is here

| Formula | Description |
| --- | --- |
| `cnips` (cask) | Command-line client for the CNIPS Integration Platform |

`cnips` is distributed as a prebuilt binary: a cask that installs the release
archive from [cnips/cnips-cli](https://github.com/cnips/cnips-cli/releases)
rather than building from source. The cask is generated by the release pipeline
on every release, with checksums from that release's `checksums.txt` — do not
edit it by hand.

Supported: macOS (Apple silicon and Intel) and Linux (x86-64 and arm64).
